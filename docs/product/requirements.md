# Rhizomind — требования (Secure-редакция, версия 1.0)

Собрано в брейншторме с владельцем продукта 24.10.2026. Это источник правды для спецификаций и планов. Решения здесь меняются только с согласия владельца.

## Цель и успех

- Первая версия — для владельца лично, дальше для его команды и отдела.
- **Успех 1.0:** владелец ведёт в Rhizomind рабочие заметки и базу знаний, а служба ИБ компании согласовала установку.
- Сроков нет.
- Процесс ИБ неизвестен. Известно: Obsidian отклонён из-за синхронизации и выходов наружу; любой канал утечки, который сложно закрыть, означает отказ. **Стратегия:** доказуемое отсутствие каналов утечки. Передаём ИБ исходный код и документацию.
- Rhizomind — самостоятельный продукт. Пользовательский опыт как в Obsidian, но совместимость с его хранилищами и точное копирование синтаксиса не требуются. Заметки — обычные `.md`-файлы.

## Редакции

| Редакция | Когда | Суть |
|---|---|---|
| Secure | сейчас | Без сети и плагинов, всё внутри хранилища. |
| Community (Open Core) | после 1.0 | Плагины, встроенный браузер, каталог тем, контролируемая сеть. |
| Server | позже | Развёртывание в контуре компании, доступ участников. |

Ядро общее. Внутренний API ядра узкий и проектируется так, чтобы позже стать границей для плагинов Community.

## Платформы и технологии

- Tauri 2: ядро на Rust, интерфейс на TypeScript (Svelte 5) в системном WebView (ADR 0008). Первая цель — Windows (установка в `Program Files`), код кроссплатформенный (macOS, Linux позже).
- Пользователи и код: владелец ставит задачи и принимает результат, код пишут агенты.

## Безопасность

- В приложении нет сетевого кода. Внешние ссылки открываются в системном браузере после подтверждения.
- Чтение и запись только внутри открытого хранилища. Вложения тоже только внутри хранилища.
- Служебная папка `.rhizomind/` в корне хранилища: только технические данные (настройки JSON, раскладка, индекс, темы, журнал ошибок; позже плагины). В дереве файлов приложения не показывается. Пользовательский контент (например, папка шаблонов) в ней не лежит.
- В профиле ОС (AppData) один файл: имена и пути хранилищ, последнее открытое хранилище, размер окна.
- Сессия браузерного движка (WebView2) только в памяти. Служебные файлы движка, которые нельзя не создавать, живут во временной папке и удаляются при выходе (ADR 0007). Дампов падений нет. Журнал ошибок в `.rhizomind/logs`, без содержимого заметок.
- Шифрования хранилища нет (защита диска средствами ОС). Появится только по требованию ИБ.

## Хранилище

- Хранилище — папка на диске. В окне открыто одно хранилище. Переключатель хранилищ слева снизу, другое хранилище открывается в новом окне.
- Ожидаемый объём: 1 000–10 000 заметок за год, закладываемся с запасом до 50 000.
- Индекс (заголовки, теги, ссылки) хранится в `.rhizomind/`, пересобирается из файлов. При запуске сверка с файлами по дате изменения и размеру, перечитываются только изменённые.
- Пока приложение открыто, изменения в папке хранилища отслеживаются в реальном времени (уведомления ОС), как в Obsidian. Переименование и перемещение в Проводнике обрабатываются так же, как сделанные в приложении. Пока приложение закрыто, ничего не отслеживается.
- Приложение никогда молча не затирает изменения, сделанные снаружи: если файл открытой заметки изменился на диске, заметка обновляется, а если в ту же секунду в редакторе есть несохранённый ввод, сохраняются обе версии (версия с диска — копией рядом). Приложение ничего не переспрашивает.
- Удаление отправляет файл в корзину ОС; на диске без корзины (флешка, сетевая папка) — безвозвратно, после отдельного подтверждения. Своей корзины и истории версий нет.
- Максимальный размер файла для редактирования задаётся в настройках каждого хранилища, по умолчанию 10 МБ.
- Файлы сохраняются в той кодировке и с теми переносами строк, какие в них были. Новые заметки — UTF-8 без BOM, перенос LF: хранилище, перенесённое архивом на другую ОС, открывается без изменений.

## Заметки и ссылки

- Ссылки `[[Заметка]]`, `[[Заметка|псевдоним]]` (обязательно: падежи в русском), `[[Заметка#Заголовок]]`, встраивание `![[файл]]`.
- Имена файлов и ссылки не зависят от языка: любые символы, допустимые в Windows. Сравнение без учёта регистра и с нормализацией Unicode.
- Уникальное имя — ссылка по имени. Повторяющееся имя — ссылка с кратчайшим различающим путём (столько папок с конца, сколько нужно для однозначности). Когда при открытом приложении появляется вторая заметка с тем же именем, существующие ссылки на первую автоматически уточняются путём. В тексте ссылка с путём показывает только имя заметки; псевдоним после `|` — только для другого текста (падежи, формы слова). Ссылка без пути при нескольких кандидатах ведёт на самую старую заметку.
- Ссылка на несуществующую заметку — нормальное состояние (заметка «запланирована»): отображается как неразрешённая, клик создаёт заметку. Сломанные ссылки не объявляются и не проверяются отдельно.
- Переименование заметки: настройка хранилища «всегда спрашивать» или «всегда обновлять ссылки». При ответе «нет» ссылки остаются на старом имени и становятся неразрешёнными.
- Теги: `#тег`, составные через подчёркивание (`#Колонния_людей`). Пишутся в тексте или в блоке свойств.
- Свойства (блок `---` в начале файла): в 1.0 приложение читает из него теги и не показывает его как текст. Интерфейс свойств — позже.

## Функции 1.0

- Дерево файлов и папок.
- Редактор с живым предпросмотром: разметка прячется при наборе. Кнопка и горячая клавиша переключают режим исходного текста: разметка видна целиком, без форматирования.
- Ссылки и обратные ссылки.
- Теги.
- Быстрый переход к заметке по имени (Ctrl+O).
- Поиск по тексту и названиям, фильтры по тегам и папкам.
- Граф как в Obsidian: весь граф, масштаб, перетаскивание узлов, подсветка связей при наведении, размер узла по числу связей, фильтры в панели (теги, вложения, заметки без связей, поиск), цветовые группы по тегу, папке или запросу.
- Вставка картинок и файлов, в том числе скриншотов из буфера обмена. По умолчанию файл сохраняется в папку заметки; в настройках можно задать свою папку внутри хранилища для каждого типа файлов.
- Шаблоны: пользователь создаёт обычную папку и отмечает её в настройках хранилища как папку шаблонов. Шаблон — готовая заметка, при создании копируется целиком.
- Таблицы Markdown.
- Свободная раскладка: вкладки и панели в любом делении окна (заметка, обратные ссылки, граф и т.д.).
- Командная палитра по горячей клавише: действия (создать из шаблона, вставить таблицу и т.п.), вставленная разметка сразу отображается в живом предпросмотре.
- Темы: тёмная и светлая встроенные; свои темы — CSS-файлы в `.rhizomind/themes`, без загрузки из приложения. Каталог тем — ссылка на GitHub в документации.
- Интерфейс на русском и английском, с заделом на другие языки.

## План выпусков 1.0

Утверждён владельцем 24.10.2026.

### Принципы

- **Вертикальные выпуски.** Каждый выпуск пригоден для ежедневной работы и даёт обратную связь. Подходы «по слоям» (ядро, потом интерфейс, потом граф) и «всё сразу до 1.0» отклонены: обратная связь приходит слишком поздно.
- **Безопасность с первого выпуска.** Инварианты Secure-редакции (см. `CLAUDE.md`) действуют с 0.1. Каждый выпуск обновляет `docs/SECURITY.md` и проходит ревью безопасности.
- **Без потери данных.** С 0.1 приложение не затирает внешние изменения файлов.
- **Задел вместо переделки.** То, что видно пользователю позже, но пронизывает весь интерфейс, закладывается с 0.1: тексты интерфейса через словарь, цвета через переменные темы, модель раскладки, узкий API ядра.
- **Маленький шаг, проверка, масштаб.** Функция сначала делается в минимальном виде, проверяется и обкатывается, потом расширяется.
- **Владелец проверяет руками.** Каждый выпуск и каждая крупная функция (например, панели в 0.4) доходят до владельца рабочей сборкой для ручной проверки.
- **Объём проверяется на каждом выпуске.** Функции выпуска проверяются на тестовом хранилище из 10 000 заметок; цель 1.0 — 50 000.

### 0.1 Основа — «пишу заметки каждый день»

- Хранилища: создать или открыть папку, переключатель слева снизу, другое хранилище в новом окне, один файл со списком хранилищ в профиле ОС.
- Дерево файлов и папок: показываются все файлы хранилища, открываются пока только заметки; создание, переименование, перемещение, удаление в корзину ОС. Ссылки при переименовании пока не обновляются; окно переименования предупреждает, что ссылки станут неразрешёнными.
- Слежение за папкой: дерево и открытая заметка обновляются при изменениях снаружи; переименования в Проводнике обрабатываются как свои; при одновременном изменении сохраняются обе версии. Автотесты слежения под нагрузкой.
- Редактор с живым предпросмотром: заголовки, выделение, списки и чекбоксы, цитаты, код, горизонтальные линии, обычные ссылки. Режим исходного текста по кнопке. Автосохранение.
- Вики-ссылки: `[[Заметка]]`, `[[Заметка|псевдоним]]`, `[[Заметка#Заголовок]]`. Переход по клику, неразрешённые ссылки отмечены, клик по ним создаёт заметку.
- Внешние ссылки: открываются в системном браузере после подтверждения.
- Быстрый переход к заметке по имени (Ctrl+O).
- Одна открытая заметка, переходы «назад» и «вперёд» (Alt+← / Alt+→). Окно уже построено на модели раскладки, вкладки добавятся в 0.4.
- Интерфейс на русском; все тексты через словарь. Встроенные тёмная и светлая темы по настройке ОС; все цвета через переменные темы.
- Инварианты безопасности, сетевой выключатель, автоматическая проверка исходников на сетевой код.
- Рабочие сборки — портативные (zip, без установки); установщик Windows — для выпусков, публикуется в GitHub Releases.

### 0.2 Связи — «вижу, как заметки связаны»

- Индекс в `.rhizomind/`: заголовки, теги, ссылки; сверка с файлами при запуске, обновление по слежению за папкой.
- Панель обратных ссылок.
- Теги в тексте и в блоке свойств; блок свойств скрыт в редакторе; список тегов.
- Обновление ссылок: при переименовании и перемещении в приложении и в Проводнике при открытом приложении (настройка хранилища «всегда спрашивать» или «всегда обновлять»); автоматическое уточнение ссылок путём при появлении дубликата имени.

### 0.3 Скорость — «быстро нахожу и создаю»

- Командная палитра.
- Шаблоны: папка шаблонов в настройках хранилища, создание заметки из шаблона.
- Поиск по тексту и названиям, фильтры по тегам и папкам. Язык запросов сразу проектируется так, чтобы на нём задавать цветовые группы графа в 0.4.
- Вложения: вставка файлов и скриншотов из буфера обмена, правила папок для вложений по типу файла.
- Встраивание `![[файл]]` (картинки и заметки).

### 0.4 Пространство — «работаю с несколькими заметками и вижу картину целиком»

- Вкладки и свободное деление окна на панели; раскладка сохраняется в `.rhizomind/`. Сразу после готовности — проверка работы с клавиатуры отдельным агентом и рабочая сборка владельцу.
- Граф: весь граф, масштаб, перетаскивание, подсветка связей, размер узла по числу связей, фильтры, цветовые группы. В базовой версии узлы — только заметки, связи без направления (направление — позже). Цветовые группы задаются поисковым запросом, как в Obsidian (по файлу, пути, тегу, строке, разделу, свойству). Движок выбирается по замеру на рабочем ноутбуке владельца со встроенной видеокартой.
- Таблицы Markdown в живом предпросмотре.

### 0.5 Для ИБ — «готово к согласованию»

- Английский интерфейс.
- Свои темы: CSS-файлы в `.rhizomind/themes`.
- Журнал ошибок в `.rhizomind/logs`: без содержимого заметок, с ограничением размера.
- Проверка на хранилище из 50 000 заметок.
- Пакет документов для ИБ и полный аудит безопасности.

### 1.0

Исправления по опыту ежедневного использования и замечаниям ИБ.

## Бэклог (не входит в 1.0)

Переменные в шаблонах (`{{дата}}` и т.п., свой синтаксис), окно «ссылка сломана, это та заметка?», интерфейс свойств, таблицы-базы, рисование (Excalidraw, Draw.io), встроенный браузер и каталог тем (Community), шифрование, история версий, расширенный поиск (точные фразы, исключения, регулярные выражения), плагины, синхронизация (Server), межхранилищные ссылки, просмотр PDF и других форматов внутри приложения (по необходимости).

## Открытые решения

1. **Отрисовка графа** — нужна к 0.4, выбор после замера на рабочем ноутбуке владельца (встроенная видеокарта) перед спецификацией 0.4. Остальные архитектурные решения приняты 24.10.2026 — ADR 0001–0009 в `docs/adr/` (ADR 0005 заменён ADR 0008).
