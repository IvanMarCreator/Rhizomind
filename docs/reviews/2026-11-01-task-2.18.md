# Задача 2.18 «Парная квадратная скобка» (01.11.2026)

Ветка `task/2.18-bracket-pairs` от `main` 5b34010. Решение владельца 95 (спецификация, раздел 12); учтены 81, 85, 86, 92, 93 и решение 75 (без новых зависимостей).

## Что сделано

Отдельное расширение `src/editor/bracket-pairs.ts` (`bracketPairs()`), подключено одной строкой в `src/editor/codemirror.ts` — работает в обоих режимах редактора. Чистые функции `openBracket`, `closeBracket`, `taskSpace`, `deletePair` возвращают правку или `null` («правило не действует, обычный ввод»).

Ввод перехватывается через `EditorView.inputHandler` (тот же путь, что у `closeBrackets` из `@codemirror/autocomplete`), а не через сочетание клавиши `[`: срабатывает по введённому символу, поэтому работает в любой раскладке, где `[` набирается (в том числе через AltGr), и не срабатывает на `х` в русской раскладке. Backspace — сочетание `Prec.high` (выше `defaultKeymap`). `@codemirror/autocomplete` в `node_modules` нет; решение своё, без стилей через `EditorView.theme`.

| Ввод | Где | Результат (`¦` — курсор) |
|---|---|---|
| `[` | перед концом строки, пробелом, `)` `]` `}`, `.` `,` `;` `:` `!` `?` | `[¦]` |
| `[` | в пустой паре `[¦]` | `[[¦]]`, открывается список подсказок вики-ссылок (вставка — `input.type`, как набранный символ, задача 2.14) |
| `[` | перед буквой или цифрой; после `\` | одна `[` (обычный ввод) |
| `[` | при выделении | `[¦выделение¦]` — выделение сохраняется внутри |
| `]` | перед `]`, вставленной парой | курсор за неё, вторая `]` не вставляется (`[[Имя]]`, `[текст](адрес)`) |
| `]` | перед чужой `]` (была в тексте) | обычный ввод |
| пробел | `- [¦]`, `* [¦]`, `+ [¦]`, `1. [¦]`, `1) [¦]`, с отступом, в цитате `> - [¦]` | `- [ ] ¦` — готовая задача, курсор после пробела за `]`; если после `]` уже пробел — второй не добавляется |
| пробел | в `[]` в другом месте | обычный пробел |
| Backspace | `[¦]` | обе скобки удаляются |
| Backspace | `[[¦]]` | `[¦]` — внутренняя пара (второй Backspace — внешняя), список подсказок закрывается |

**Курсор после пробела в задаче (решение исполнителя).** В Obsidian после `- [` + пробел курсор остаётся внутри `[ ]`. Владелец просил «готовую структуру», поэтому курсор ставится **после** `- [ ] ` — следующая печать сразу идёт текстом задачи. Отметить задачу можно, набрав `x` внутри пустой пары до пробела (`- [x]`, затем `]` перескакивает).

**Backspace в `[[]]` (решение исполнителя).** Как в Obsidian и `closeBrackets`: удаляется внутренняя пара, остаётся `[]`. Правило одно для всех пар, предсказуемо; два нажатия очищают всё.

**Пара не перед словом (решение исполнителя).** Как `closeBrackets` CodeMirror (на нём автопара Obsidian): перед буквой/цифрой — одна `[`. Иначе нельзя взять в скобки уже написанное слово (`[слово](адрес)`, `[[слово]]` по одной `[` слева и `]` справа). После `\` (экранированная скобка Markdown) — тоже одна.

**Какие `]` перескакиваются.** Только вставленные парой: их позиции хранит поле `closingField` (переносится по правкам). Скобка забывается, если её удалили или заменили, и когда курсор ушёл с её строки. Набор `]` перед `]`, которая уже была в тексте, вставляет новую — текст, которого не трогали, не «съедается».

**Где правило не действует.** Код в строке, блок кода (в том числе строка ограды), блок свойств — по `inCodeAt` из `live-preview/index.ts` (поле `blockTracking` есть в обоих режимах); только чтение; набор через IME (`view.composing || view.compositionStarted`); ввод, заменяющий не выделение (например, автозамена браузера).

**Отмена.** Каждая правка — одна транзакция, `userEvent: 'input.type'`: Ctrl+Z убирает `[]` целиком, одиночная `[` не остаётся. Как и у обычного набора, история CodeMirror склеивает подряд набранные символы в один шаг (в пределах полсекунды), поэтому Ctrl+Z сразу после быстрого «текст [» убирает и текст — это то же поведение, что без автопары.

**Взаимодействие.**
- Подсказки `[[` (2.6, 2.14): список открывается от вставки пары `[[]]` (проверено тестом), выбор Enter/Tab заменяет цель вместе с уже стоящими `]]` (`targetEnd`) — скобки не удваиваются. `autocomplete.ts` не менялся.
- Продолжение списков (2.15): задача, набранная `- [` + пробел, продолжается Enter как `- [ ] `; после Enter `[` + пробел в новом пункте тоже дают задачу.
- Живой предпросмотр (2.16): правила — только ввод, оформление не меняется; на снимке сценария строка `- [ ] task` с курсором показывает маркер задачи.
- Правило 81: Backspace — клавиша правки, окно её не перехватывает; реестр горячих клавиш не менялся.
