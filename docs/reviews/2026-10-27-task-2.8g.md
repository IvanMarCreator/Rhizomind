## Исправления по QA (27.10.2026)

- **Регресс: команды окна в поле переименования.** Перехват в фазе capture запускал Ctrl+N/O/E и Alt+← в поле имени (поле теряло фокус и сохраняло недописанное имя). Теперь для `input`/`textarea`/`select` окно проверяет нажатие на всплытии, как до 2.8г: поле переименования останавливает нажатие, команды не выполняются. Правило 81 (клавиши правки текста не уходят окну) действует в тексте заметки и в остальных полях. Тест — `Settings.component.test.ts`, «поле переименования и команды окна» (4 сочетания).
- **Порча экрана при ошибке записи.** Одно значение дважды подряд, первая запись упала — откат показывал старое при новом на диске. Теперь каждая правка помнит, какие поля она меняла последней (`#latestPatch`); по окончании записи (`#settle`) её поля показывают записанное (при ошибке — последнее удачно записанное), только если их не поменяла более поздняя правка. Тесты: «одно значение дважды подряд…», «первая запись упала, а поле уже поменяла вторая…» (без проверки «последней правки» падает).
- Решение 80 в спецификации переписано по факту (фаза перехвата, поля формы — на всплытии).
