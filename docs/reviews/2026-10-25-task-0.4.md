- `.rhizomind/` недоступна обычными командами: сравнение по ключу имени (`.Rhizomind`, `.RHIZOMIND`), короткие имена 8.3 (`RHIZOM~1`), проверка итогового пути через `GetFinalPathNameByHandle` после открытия.
- Гонка «проверил — открыл»: проверка контура по уже открытому дескриптору там, где возможно; остаточный риск — в `SECURITY.md`.
- Жёсткие ссылки (hard links) на файлы вне хранилища — описать в `SECURITY.md` (контуром их не отличить).
- Свои записи для наблюдателя: хэш и размер новой версии запоминаются до замены файла, чтобы событие о замене не стало внешним изменением.
- Реализовать правило «байт в байт» из `commands/note.rs` и сохранение даты создания из описания модуля `vault`.

## В задачу 1.3 «Список хранилищ и окна»

- Отвязка окна от хранилища по `WindowEvent::Destroyed` (`Core::bind_window` → парная отвязка).

## Повторное ревью 0.4.1 (25.10.2026)

Все 17 пунктов сделаны, слияние корректно, CI зелёный. Передаётся дальше:

1. **1.7 / 2.4 (в первую очередь):** `note_write` проверяет текст по лимиту из *текущих* настроек; по С3.3 новый лимит действует при следующем открытии. Снижение лимита при открытой большой заметке уронит автосохранение. В `note_write` проверять только жёсткий потолок 100 МБ, лимит из настроек применять при открытии (`read_only`).
2. **1.2 / 1.7:** `note_create`, `folder_create`, `entry_rename` не вызывают `names::check` в слое команд (в отличие от `vault_create`, `name_check`), а `Vault::check_new_name` считает, что правила уже проверены. Закрепить проверку в слое команд.
3. **1.3 / 1.7:** когда `registry::pick_folder` станет настоящим, `acl_tests` откроет системный диалог под MockRuntime и может зависнуть в CI — нужен подменяемый выбор папки.
4. **до 1.2:** дописать ADR 0006 (`ReplaceFileW` сохраняет дату создания; на Linux дата может сдвинуться — «самая старая» может смениться после правки; известное ограничение до перехода на Linux).

Пожелания: не делать копию конфликта, если хэш на диске равен хэшу ожидаемой версии (git checkout без изменений содержимого); терпимое чтение `format_version` любого типа; не затирать неизвестное значение настройки (`"theme":"sepia"`) при записи; исправить ссылку на `src/api/limits.test.ts` в `contract_tests.rs:802`; проверка полноты массивов `ErrorCode::ALL`/`NameProblem::ALL`; одиночный `\r` в правиле «байт в байт» — учесть в 2.4.
