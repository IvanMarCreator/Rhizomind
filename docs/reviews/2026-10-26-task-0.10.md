## Изменения поведения приложения

Только случай 1: на Windows наблюдатель больше не открывает файлы ради
идентификатора — `docs/SECURITY.md`, строка «Слежение за папкой». Новых
записей, сетевого кода и крейтов нет (`windows-sys` 0.61.2 — те же функции
`Win32_Storage_FileSystem`).

## Наблюдения вне задачи

- 0.7 заменила в `close.test.ts` переименование папки хранилища файлом-признаком
  с пояснением «на Windows папку под наблюдателем не переименовать». Опыт 0.10
  это уточняет: сам наблюдатель (дескриптор корня) переименованию корня не
  мешает; мешает любой открытый файл внутри в эту секунду — у тех прогонов шла
  запись заметки и проверка своих записей (`own_writes.rs` открывает файл).
  Это обычное поведение Windows для открытых файлов.
- Служебное окно tao «Tao Thread Event Target» видимо для Windows
  (`IsWindowVisible`): `MainWindowHandle` и подобные средства могут принять его
  за окно программы. На работу программы не влияет.
