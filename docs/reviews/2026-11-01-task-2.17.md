# Задача 2.17 «Сочетания браузерного движка не действуют в окне» (01.11.2026)

Ветка `task/2.17-engine-shortcuts` от `main` 5b34010 (+ fd97193 — решение владельца 96). Решения владельца 94, 96 (спецификация, раздел 12), с учётом решений 80, 81.

## Как выключено

Два рубежа.

1. **Движок (Windows, главный).** После создания окна ядро выставляет `ICoreWebView2Settings3::AreBrowserAcceleratorKeysEnabled = false` (`disable_browser_accelerator_keys` в `src-tauri/src/security/windows.rs`, вызов в `harden_platform_webview`, `src-tauri/src/lib.rs`) — рядом с выключением SmartScreen, до показа окна. В wry настройка есть (`with_browser_accelerator_keys`), но Tauri 2.12.5 её не передаёт, поэтому правка `vendor/wry` не понадобилась. Масштаб: `IsZoomControlEnabled` и `IsPinchZoomEnabled` выключает wry по `zoom_hotkeys_enabled` (в Tauri по умолчанию `false`); теперь `zoom_hotkeys_enabled(false)` стоит в `build_window` явно.
   - По документации Microsoft настройка выключает «все сочетания возможностей браузера»: Ctrl+F/F3 (поиск), Ctrl+P (печать), Ctrl+R/F5 (перезагрузка), Ctrl+плюс/минус (масштаб), Ctrl+Shift+C/F12 (средства разработчика), клавиши «Назад», «Вперёд», «Поиск» — и не трогает перемещение и правку текста (Home/End/PgUp/PgDn, Ctrl+X/C/V, Ctrl+A, Ctrl+Z). Полного списка Microsoft не публикует.
   - Нажатие при этом доходит до страницы — проверено настоящими нажатиями (SendInput) в `src-tauri/tests/webview2_runtime.rs`, поэтому команды реестра горячих клавиш (Ctrl+P → «Быстрый переход») работают.
2. **Интерфейс (запасной; на Linux — единственный).** `src/shell/engineShortcuts.ts`: список сочетаний движка (Edge/Chromium, WebKitGTK). Оболочка (`onKeydownBubble` в `src/shell/Shell.svelte`) гасит `preventDefault` такое нажатие **на всплытии, последней** — если оно не стало командой реестра и элемент (редактор, поле) его не обработал. Поэтому:
   - назначенное сочетание выполняет команду (решение 80 — фаза перехвата — не изменилось);
   - обработчики CodeMirror получают нажатие раньше (например, Ctrl+Shift+K, Ctrl+L редактора не ломаются);
   - клавиши правки текста (решение 81), Tab, Esc, Alt+F4, Shift+F10 и AltGr (Ctrl+Alt+…) в список не входят — тест сверяет список с `isTextEditingKey` и `hotkey_reserved`.
   - Ctrl+колесо (и щипок на сенсорной панели) гасится `blockEngineZoom(document)` в `src/main.ts`.
   - Окно «Управление хранилищами» и загрузка окна — тоже под рубежом (обработчик оболочки стоит всегда).

Решение 96: Ctrl+P, Ctrl+F, F12 по умолчанию не назначены и ничего не делают; назначить их команде можно (`checkChord` → `null`; в `hotkey_reserved` их нет, F12 — в `hotkey_bare_keys`). Правка списков ядра не понадобилась.

## Полный список запасного рубежа

Печать: Ctrl+P, Ctrl+Shift+P. Поиск: Ctrl+F, Ctrl+G, Ctrl+Shift+G, F3, Shift+F3. Перезагрузка/остановка: Ctrl+R, Ctrl+Shift+R, F5, Ctrl+F5, Shift+F5, BrowserRefresh, BrowserStop. Страница: Ctrl+U, Ctrl+S, Ctrl+Shift+S, Ctrl+J, Ctrl+H. Разработчик: F12, Ctrl+Shift+I/J/C, Shift+Esc. Масштаб: Ctrl+=, Ctrl+Shift+=, Ctrl+−, Ctrl+Shift+−, Ctrl+0, Ctrl+Numpad+/−/0, Ctrl+колесо. Навигация: Alt+←/→, Alt+Home, BrowserBack/Forward/Home/Search/Favorites. Окна и вкладки: Ctrl+N, Ctrl+Shift+N, Ctrl+T, Ctrl+Shift+T, Ctrl+W, Ctrl+Shift+W, Ctrl+F4, Ctrl+Tab, Ctrl+Shift+Tab, Ctrl+PgUp/PgDn, Ctrl+Shift+K, Ctrl+Shift+A, Ctrl+1…9. Адресная строка, закладки, профиль: Ctrl+O, Ctrl+L, Alt+D, F6, Shift+F6, Ctrl+E, Ctrl+K, Ctrl+D, Ctrl+Shift+D, Ctrl+Shift+B, Ctrl+Shift+O, Ctrl+Shift+M, Ctrl+M. Меню, отзыв, чтение вслух: Alt+F, Alt+E, F10, Alt+Shift+I, Ctrl+Shift+U. Прочее: F7 (режим каретки), F1 (справка), F11 (полный экран).

Ctrl+N, Ctrl+O, Ctrl+E, Alt+←/→ в списке ради случая «пользователь снял сочетание с команды»: пока они назначены, срабатывает команда.

## Тесты

- `src/shell/engineShortcuts.test.ts` — список (по физической клавише, русская раскладка, Cmd, пустой `code`, IME), что не трогается (правка текста, Tab, Esc, Alt+F4, AltGr), назначаемость Ctrl+P/Ctrl+F/F12.
- `src/shell/engineShortcuts.component.test.ts` — Ctrl+колесо.
- `src/shell/Shell.component.test.ts`, блок «сочетания браузерного движка» — не назначенные гасятся и ничего не открывают; назначенное Ctrl+P открывает быстрый переход (и из поля формы); Ctrl+N без назначения не создаёт заметку; правка текста, Tab, Esc, AltGr в поле и тексте не гасятся; элемент получает нажатие раньше рубежа; окно управления хранилищами.
- `src-tauri/tests/webview2_runtime.rs` (Windows, живой движок) — `AreBrowserAcceleratorKeysEnabled = false`, `IsZoomControlEnabled = false`; настоящие нажатия Ctrl+P, Ctrl+F, Ctrl+=, Ctrl+Shift+I, F12, F5 доходят до страницы, `beforeprint` нет, страница не перезагрузилась, `devicePixelRatio` не изменился (запасной рубеж интерфейса в этой проверке отключён). Контроль детектора: с включёнными на время ускорителями Ctrl+P — ожидается `beforeprint` (в журнал).
- `tests/e2e/engine-shortcuts.test.ts` (WebDriver, обе ОС) — Ctrl+P, Ctrl+F, F5, Ctrl+=, Ctrl+− в тексте заметки гасятся, печати, перезагрузки и масштаба нет; Ctrl+O работает; Ctrl+A + ввод заменяют текст; с назначением Ctrl+P открывает быстрый переход. Снимки `engine-shortcuts-none`, `engine-shortcuts-assigned`.

## Ограничения

- Поле переименования в дереве останавливает всплытие у себя — запасной рубеж его нажатий не видит; на Windows их закрывает движок, на Linux у WebKitGTK печати и поиска по сочетаниям нет.
- Окно печати WebView2 — часть движка, не отдельное окно ОС: из WebDriver его не видно. Признак печати — событие `beforeprint` страницы.

## Ручная проверка владельцем (Windows)

1. Окно хранилища, фокус в тексте заметки: Ctrl+P — окна печати нет; Ctrl+F — панели поиска движка нет; F5, Ctrl+R — заметка не перезагружается, ввод не теряется; Ctrl+U, Ctrl+S, Ctrl+J, Ctrl+H, F12, Ctrl+Shift+I, F7 — ничего не открывается.
2. Ctrl+колесо, Ctrl+=, Ctrl+−, Ctrl+0 — масштаб страницы не меняется.
3. Настройки → Горячие клавиши: назначить Ctrl+P «Быстрому переходу» — Ctrl+P открывает быстрый переход; снять — снова ничего.
4. Не сломалось: Ctrl+C/V/X/Z/Y/A, Ctrl+стрелки, Ctrl+Backspace/Delete в тексте и в поле поиска; Tab; русский ввод; Ctrl+O, Ctrl+N, Ctrl+E, Alt+←/→; F2 и Delete в дереве; Esc закрывает окна; Alt+F4 закрывает окно.
5. То же — в окне «Управление хранилищами» (Ctrl+P, F5).
