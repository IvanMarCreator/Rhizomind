# Задача 2.19 «Своё контекстное меню вместо меню движка» (01.11.2026)

Ветка `task/2.19-context-menu` от `main` 31850a2. Решение оркестратора 97 (спецификация, раздел 12), следует из решений 94/96 и инварианта 4.

## Что найдено

Tauri 2.12.5 не передаёт `with_default_context_menus`, и wry оставляет `AreDefaultContextMenusEnabled = true` (`vendor/wry/src/lib.rs:1769`). Действие `contextmenu` гасило только дерево. В меню WebView2 есть «Обновить», «Сохранить как», «Печать»; у WebKitGTK — «Назад/Вперёд/Обновить».

## Как выключено

1. **Движок (Windows).** `disable_browser_accelerator_keys` (2.17) дополнена соседней мерой `disable_default_context_menus`, `src-tauri/src/security/windows.rs`: она ставит `ICoreWebView2Settings::AreDefaultContextMenusEnabled = false` в `harden_platform_webview` (`src-tauri/src/lib.rs`) — в каждом окне, до показа.
2. **Интерфейс (на Linux — единственный рубеж).** `blockEngineContextMenu(document)` в `src/main.ts` гасит действие `contextmenu` по умолчанию в фазе перехвата, везде. Распространение события не останавливается: своим меню (дерево, правка текста) событие доходит.
3. **Своё меню правки текста** (`src/shell/textMenu.ts`, показывает `Shell.svelte`): в тексте заметки (CodeMirror, находится через `EditorView.findFromDOM`) и в полях ввода (`input` текстовых типов, `textarea`).
   - Пункты: «Вырезать» (Ctrl+X), «Копировать» (Ctrl+C), «Вставить» (Ctrl+V), «Выделить всё» (Ctrl+A).
   - Без выделения «Вырезать/Копировать» серые; в режиме только чтения серый «Вырезать».
   - «Вставить» пока серый всегда (см. «Вопрос ИБ»).
   - «Вырезать/Копировать» возвращают фокус в редактор или поле и выполняют команду движка `copy`/`cut`. CodeMirror обрабатывает их своим обработчиком буфера; чтения буфера страницей при этом нет. «Выделить всё» — `selectAll` CodeMirror или `select()` поля.
   - Правый щелчок вне выделения ставит курсор в точку щелчка (`posAtCoords`), внутри выделения — оставляет выделение.
   - Shift+F10 и клавиша меню открывают меню у курсора.
4. **Общий компонент меню** `src/shell/ContextMenu.svelte` (бывший `src/tree/TreeMenu.svelte`, вид по макету меню дерева):
   - новые возможности: название меню и неактивные пункты — серые, `aria-disabled`, клавиатурный фокус их пропускает;
   - если активных пунктов нет, фокус ставится на само меню, чтобы работал Esc;
   - слой поднят до 60 — меню видно и над окном настроек;
   - клавиатура: ↑/↓, Home/End, Enter, Esc, Tab; меню закрывается и щелчком мимо.
5. **Мелкие правки.** В поле переименования дерева теперь меню правки текста, а не меню дерева (`FileTree.svelte`). Быстрый переход отпускает фокус в меню над своим полем (`QuickSwitcher.svelte`, `onFocusIn`); после закрытия меню фокус возвращается в поле.
6. **Остальные места** (лента, шапка, пустая область, окно управления хранилищами): правый щелчок ничего не делает. Меню дерева — как было.

## Вопрос ИБ: «Вставить»

Программно прочитать буфер страница может только через Clipboard API (`navigator.clipboard.readText`):
- в WebView2 это запрос разрешения ClipboardRead (`vendor/wry/src/webview2/mod.rs:534,561`), а все разрешения страницы отклоняются (`on_permission_request`);
- в WebKitGTK нужно `javascript_can_access_clipboard`;
- `execCommand('paste')` страницам недоступен.

Ctrl+V работает: это встроенная вставка движка. Вопрос с вариантами (1 — серый пункт, сделано; 2 — разрешить ClipboardRead своему источнику; 3 — команда ядра) отправлен оркестратору.

## Ручная проверка владельцем (Windows)

1. Правый щелчок в тексте заметки: меню Rhizomind из четырёх пунктов, без «Обновить», «Сохранить как», «Печать». Без выделения «Вырезать/Копировать» серые; «Вставить» серый.
2. Выделить слово → правый щелчок по нему → «Копировать» → Ctrl+V в другом месте вставляет слово. «Вырезать» убирает слово. «Выделить всё» выделяет заметку.
3. Правый щелчок по другому слову без выделения ставит туда курсор.
4. Правый щелчок в поле быстрого перехода (Ctrl+O), в поле переименования, в числовых полях настроек — то же меню. Esc закрывает меню, фокус остаётся в поле.
5. Правый щелчок по ленте, шапке, пустой области, в окне «Управление хранилищами» — ничего. В дереве — меню дерева.
6. Shift+F10 в тексте — меню у курсора; стрелки, Enter, Esc работают.
