## Передаётся в задачу 1.7 «Команды ядра на настоящих модулях»

- **Общий замок диалогов ядра.** Сейчас замок «одно окно подтверждения на окно приложения» живёт внутри `external_links` (`DialogSlot`). В 1.7 появятся другие диалоги ядра — выбор папки хранилища и подтверждение безвозвратного удаления. Нужен один общий замок на окно для всех диалогов ядра, иначе ссылка и удаление могут показать два модальных окна одновременно. Ответ на занятое окно для ссылки сейчас — `cancelled` (отдельного кода «занято» в контракте нет).
- Название заметки в тексте окна («Ссылка из заметки «…»» из макета Э6б) не показывается: в запросе `open_external` его нет. Если нужно — решение оркестратора об изменении контракта.

## Передаётся в переход на Linux

- Передача ОС — крейт `open` (`xdg-open` и др.): адрес уходит отдельным аргументом без оболочки, но обработчик протокола выбирает рабочий стол пользователя; гарантий класса протокола, как у `ShellExecuteExW`, нет — нужна своя проверка (например, через портал `org.freedesktop.portal.OpenURI`).
- Окно подтверждения GTK (rfd) не модально к окну заметки и не задаёт кнопку по умолчанию — гарантии «Открыть по умолчанию» и модальности на Linux нет. Нужен свой диалог или правка rfd.

## Повторное ревью: «можно сливать»; пожелания для задачи 1.7

1. На машине пользователя проверить, что `ShellExecuteExW` с `lpClass="http"`/`"https"` открывает браузер, выбранный по умолчанию (`UserChoice`), а не зарегистрированный обработчик класса. Если нет — определять обработчик через `AssocQueryStringW` с `ASSOCF_IS_PROTOCOL` или `IQueryAssociations`.
2. Знак `%` пропускать только в виде `%HH` (две шестнадцатеричные цифры), одиночный `%` отклонять.
3. Дописать в `docs/SECURITY.md` остаточный риск: если обработчик протокола зарегистрирован через `cmd /c …`, знак `&` из адреса (допустимый символ RFC 3986) может разделить команды; Rhizomind на регистрацию обработчиков не влияет.
4. В `body` у `mailto` отклонять управляющие символы, кроме `\r`, `\n`, `\t`.
5. В комментариях `external_links/mod.rs` и у поля `Confirmation::open_label` упомянуть подпись «Открыть в почте» для `mailto`.
6. Дополнить `clippy.toml`: `std::net::UdpSocket::connect`, `std::net::TcpStream::connect_timeout`.
