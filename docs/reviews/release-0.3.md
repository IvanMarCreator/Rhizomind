Критерии приёмки и команды воспроизведения приведены в [плане выпуска](../plans/2026-11-26-release-0.3-plan.md). Результаты ниже относятся к указанным версиям.

| Кандидат | Проверка | Наблюдение |

### Оконные проверки и архив Windows

27 ноября независимый QA принял палитру и создание из шаблона на дереве `b6885337`. На Windows QA повторил создание, правку и перезапуск в обеих темах. Содержимое исходных шаблонов сохранилось побайтно. В Ubuntu CI прошла также проверка публикации файла при перемещении либо удалении цели. Все восемь заданий приёмочного прогона завершились успешно. [Прогон двух ОС](https://github.com/IvanMarCreator/Rhizomind/actions/runs/45792502761)

На GitHub в версии `6510c467` палитра прошла 5 из 5 и шаблоны 1 из 1 сценария на каждой ОС. При полном прогоне Windows прошли 162 из 162 оконных тестов. На Ubuntu прошли 146, ещё 16 штатно пропущены. [Снимки Windows](https://github.com/IvanMarCreator/Rhizomind/actions/runs/45792502761/artifacts/15104789248) · [Снимки Ubuntu](https://github.com/IvanMarCreator/Rhizomind/actions/runs/45792502761/artifacts/15105907273)

Предварительную сборку с палитрой и шаблонами из `38ae3fc6` также проверили как отдельный архив Windows x64. EXE из распакованного архива открыл видимое окно хранилища и штатно завершился с кодом 0. Архив содержит EXE без WebDriver и лицензию. SHA-256 архива — `125A79AF9985F81ECC658538F097A50F52C16B2FB4B2034404BB1DC2FEBEA7D2`. В метаданных предварительной сборки сохранена версия 0.2.0. На тестовой сборке из этого же коммита оконный сценарий прошёл за 55,54 с, получены восемь снимков.

## Полнотекстовый поиск

В предварительном оконном замере Windows на 50 000 заметок каждый запрос ввели пять раз. Измеряли время от передачи строки полю поиска до кадра, в котором появилась строка результата. Для этого объёма значения справочные. Сравнение с Ctrl+O проводилось в том же окне.

| отчёт | 361,1 / 449,1 / 457,9 / 535,0 / 394,6 | 449,1 |

На 10 000 заметок оконный тест версии `e45464d` останавливал таймер только после появления всех 50 строк. Это произошло во всех 25 попытках. Ни одна из пяти медиан не уложилась в 200 мс.

На публичной версии `11020f25` проверка Ubuntu нашла ещё одно отклонение. У переключателя «Упоминания без ссылки» в `src/search/SearchDialog.svelte` отсутствует обязательный для всех полей атрибут `spellcheck="false"`. Остальные 2613 тестов интерфейса прошли. В этом прогоне проверка завершилась до запуска тестов ядра. Оба локальных запуска `cargo deny` для приложения и генератора прошли. ## Вставка вложений

В локальной версии `900a8f91` можно настроить папки назначения по расширению файла. На Windows прошли тесты настроек и контракта IPC, Clippy, проверка типов, ESLint и 32 теста интерфейса настроек. Независимый QA проверил сохранение и удаление правил, чтение старых настроек и сохранность полей будущих версий. На Ubuntu прошли тесты папок назначения и файловых ссылок. Описание хранения и лимита 4 МиБ проверено в `d60933a8`. Полный сценарий вставки файла и скриншота проверяется отдельно.
