# Задача 2.16 «Разметка только у элемента с курсором» (01.11.2026)

Ветка `task/2.16-reveal-element` от `main` d49451d (+ слияние 458ae4a — уточнение владельца к решению 93). Решение владельца 93 (спецификация, раздел 12), уточнение решения 76.

## Правило

Разметка видна (приглушённо, `cm-rz-markup`) только у **раскрытого** элемента. Элемент раскрыт, если хотя бы один диапазон выделения (курсор — пустой диапазон) задевает элемент **включая края**: `range.from <= owner.to && range.to >= owner.from`.

| Что | Элемент (`owner`) | Когда раскрыт |
|---|---|---|
| `**ж**`, `*к*`, `~~з~~`, `` `к` `` | от первого открывающего до последнего закрывающего символа | курсор внутри или сразу перед `**` / сразу после закрывающих `**` |
| `[текст](адрес "т")` | от `[` до `)` | то же; курсор в адресе — тоже раскрыт |
| `[[…]]` (и « › » заголовка) | от `[[` до `]]` | то же |
| `#`, закрывающие `##`, `>` всех уровней, `-`/`*`/`+`, `[ ]`/`[x]`, линия | **вся строка** (уточнение владельца 01.11.2026) | курсор где угодно на строке |
| Номер `1.` | не прячется (как раньше) | — |
| Блок кода с оградой | весь блок | как раньше: курсор в любой строке блока |

- Несколько элементов на строке: раскрыт только тот, которого касается курсор. Два элемента вплотную (`**а**|~~б~~`) — курсор между ними касается обоих, раскрыты оба.
- Вложенность: раскрыты все элементы, содержащие курсор (`~~**а|**~~` — оба; `~|~**а**~~` — только внешний; `[т| **ж**](…)` — только ссылка).
- Выделение: раскрыты все элементы, задетые любым из диапазонов; выделение на несколько строк раскрывает маркеры блоков всех задетых строк.
- «↗» у внешней ссылки — только у нераскрытой (у раскрытой адрес и так виден).
- Ввод: `**жир|` — не элемент (нет пары), разметка видна как текст; набрали закрывающие `**` — курсор сразу за элементом, он раскрыт; курсор ушёл — оформлен. Проверено тестом.

## Щелчки (решения 76 и 93)

- Обычный щелчок по **нераскрытой** ссылке (Markdown или вики) открывает её, по **раскрытой** — уходит в CodeMirror (курсор для правки). Ctrl+щелчок открывает всегда. Раскрытость ссылки под щелчком считается по её `link` (вся ссылка со скобками) — `linkRevealedAt` в `index.ts`; прежде — по строке (`revealedAt`).
- Чекбокс: щелчок по значку меняет ровно 1 символ (`taskToggle`, без изменений). Значок есть, только пока курсор не на строке задачи (маркер блока = вся строка) — как и до 2.16, когда раскрывалась вся строка.

## Стрелки и края

`EditorView.atomicRanges` в проекте не используются (проверено поиском) — курсор ходит по символам текста, а скрытые `Decoration.replace` не атомарны. Неожиданных «невидимых шагов» нет, потому что элемент раскрывается уже **на краю**: чтобы шагнуть внутрь разметки, курсор сначала встаёт вплотную к элементу, элемент раскрывается, и следующий шаг идёт по видимому символу. Пример: `а| **ж**` → → `а |**ж**` (здесь `**` появляются справа от курсора, текст сдвигается вправо) → → `а *|*ж**`. Обратно так же: с `**ж**|` элемент уже раскрыт.

- Маркер блока раскрывается, как только курсор пришёл на строку (стрелкой ↑/↓, → с конца предыдущей строки, щелчком): текст строки сдвигается на ширину маркера — так же, как раньше (строка целиком), и как в Obsidian.
- ↑/↓ с другой строки ставит курсор по координате на прежней раскладке; внутрь скрытого участка CodeMirror по координате не попадает (только на его край), а край раскрывает элемент.
- Инвариант закреплён тестом: в строках со всеми видами элементов для **каждой** позиции курсора ни один скрытый участок не содержит курсор строго внутри (`preview.test.ts`, «стрелки: курсор ни в одной позиции не оказывается внутри скрытой разметки»).
- Щелчок мышью по оформленному жирному/курсиву ставит курсор внутрь — элемент раскрывается, текст после него сдвигается на ширину разметки (как в Obsidian).
