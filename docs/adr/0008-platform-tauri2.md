# ADR 0008. Платформа: Tauri 2, ядро на Rust

Статус: принято 24.10.2026. Заменяет ADR 0005 (Electron 45). Пересматривает ADR 0006 и 0007.

## Контекст
После каркаса на Electron владелец пересмотрел платформу. Цели: меньше чужого кода и размер, ядро на языке с защитой памяти, работа на слабых рабочих ноутбуках, путь к macOS и Linux.

## Решение
- **Tauri 2.** Ядро — Rust. Интерфейс — Svelte 5 + CodeMirror 6 (ADR 0001, 0002 без изменений) в системном WebView: WebView2 на Windows, WKWebView на macOS, WebKitGTK на Linux.
- Интерфейс вызывает ядро только через команды Tauri, разрешённые явно (capabilities). Это и есть API ядра (С5.5 спецификации 0.1).
- Каркас на Electron сохранён в ветке `archive/electron-skeleton` как справочник (CI, проверочные скрипты, протокол, тесты).

## Почему
- Ядро на Rust: защита от ошибок работы с памятью; файлы, слежение за папкой, корзина и SQLite — обычные библиотеки Rust без нативных модулей Node.
- Встроенная система разрешений для вызовов из интерфейса.
- Установщик около 10 МБ против ~150 МБ у Electron.
- WebView2 обычно уже есть на рабочих машинах (на нём работают новые Outlook и Teams) и может быть знаком службе ИБ.

## Последствия и риски
- **Движок не наш.** На Windows WebView2 по умолчанию обновляет Microsoft или служба ИТ. Режим поставки (Evergreen или фиксированная версия) — отдельное решение владельца; принят Evergreen, фиксированная версия — запасной вариант (ADR 0007).
- **Сетевые функции WebView2** (SmartScreen включён по умолчанию и др.) нужно выключить и доказать отсутствие запросов; исследование и меры — в обновлённом ADR 0007, граница ядро — интерфейс — в ADR 0009.
- **Три разных движка** на трёх ОС: интерфейс и граф проверяются на каждой; известны проблемы WebGL в WebKitGTK (Linux) — учесть при выборе движка графа.
- **Тесты:** сценарные тесты — через WebDriver (tauri-driver); интерфейс отдельно тестируется в браузере с подменой команд ядра.
- Переписываются: ADR 0006 (слежение — крейт Rust), ADR 0007 (следы и сеть WebView2), раздел 5–8 спецификации 0.1, задачи этапов 0–1 плана 0.1, `docs/SECURITY.md`.

## Отклонено
Electron (ADR 0005): больший объём чужого кода и размер; оставлен в архивной ветке. Нативный интерфейс на Rust без веб-движка (Slint, Iced, egui): редактор, граф и панели пришлось бы писать с нуля.
