# ADR 0003. Раскладка: своя модель, dockview для отрисовки

Статус: принято 24.10.2026.

## Контекст
Свободная раскладка (вкладки и панели) нужна в 0.4, но окно строится на модели раскладки с 0.1. Раскладка хранится в `.rhizomind/`.

## Решение
- **Своя модель** «дерево разбиений и вкладок» со своим форматом JSON и номером версии формата. С 0.1 в ней одна панель.
- В 0.4 отрисовку и перетаскивание берёт `dockview-core` (без фреймворка и зависимостей) за тонкой обёрткой. Формат dockview в хранилище не попадает.

## Последствия
- dockview можно заменить, не трогая хранилища пользователей.
- Как только панели готовы, отдельный агент проверяет работу с клавиатуры, а владелец получает рабочую сборку для ручной проверки. Если dockview не проходит проверку, заменяем его своей реализацией за той же обёрткой.

## Отклонено
Всё своё, включая перетаскивание: больше работы в 0.4. flexlayout-react: только React. Golden Layout: заброшен с 2022.
