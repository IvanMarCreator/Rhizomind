# ADR 0002. Фреймворк интерфейса: Svelte 5 + Vite

Статус: принято 24.10.2026.

## Контекст
Редактор, граф и раскладка — независимые от фреймворка виджеты. Фреймворк отвечает за остальной интерфейс: дерево файлов, окна, настройки, переключатель хранилищ. Для ИБ важен малый объём чужого кода.

## Решение
Svelte 5 (без SvelteKit) со сборкой Vite. Тесты — Vitest, Testing Library для Svelte; сценарии — WebDriver (tauri-driver) по ADR 0008. (До ADR 0008 сценарии планировались в Playwright с Electron — заменено.)

## Почему
Компактный результат сборки и мало зависимостей. Виджеты встраиваются естественно: монтирование при появлении компонента, очистка при удалении.

## Последствия
Готовых компонентов меньше, чем у React; недостающее пишем сами. Мета-фреймворки (SvelteKit и подобные) не используем.

## Отклонено
React 19: больше зависимостей, сложнее с императивными виджетами. Без фреймворка: весь интерфейс вручную.
