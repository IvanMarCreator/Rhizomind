# ADR 0009. Безопасность границы ядро — интерфейс в Tauri

Статус: принято 24.10.2026. Дополняет ADR 0007 и 0008.
Основания: [исследование безопасности Tauri 2 и WebView2](../research/2026-10-24-tauri-webview2-security.md), [исследование крейтов Rust](../research/2026-10-24-rust-crates.md), ревью безопасности каркаса Electron (ветка `archive/electron-skeleton`).

## Контекст
Интерфейс (Svelte 5 + CodeMirror 6 в WebView2) показывает содержимое заметок — данные, которым нельзя доверять: в заметке может оказаться HTML или ссылка `javascript:`. Граница между интерфейсом и ядром должна выдерживать сценарий «в интерфейсе выполнился чужой скрипт»: такой скрипт не должен получить ни сети, ни файлов вне хранилища, ни способа открыть ссылку без подтверждения.

В Tauri по умолчанию: CSP выключен, isolation pattern выключен, `freezePrototype` выключен, **свои команды доступны всем окнам**, пока их не ограничить. Плагин `opener` с правом `default` открывает любую http(s)-ссылку без подтверждения; плагин `dialog` тянет `fs` и расширяет его область.

## Решение

### Страница интерфейса
- **CSP** задаётся в `tauri.conf.json` и не содержит внешних хостов:
  `default-src 'self'; script-src 'self'; style-src 'self'; connect-src ipc: http://ipc.localhost; img-src 'self' asset: http://asset.localhost blob: data:; object-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'`.
  На Windows интерфейс и вызовы ядра идут через `http://tauri.localhost` и `http://ipc.localhost`: эти адреса перехватывает wry внутри процесса приложения, до сети они не доходят. Tauri добавляет в CSP хэши своих скриптов. Точная строка уточняется в задаче каркаса и проверяется тестом.
- **Isolation pattern** включён: каждый вызов ядра проходит через изолированный iframe и шифруется (AES-GCM); код в изолированном iframe проверяет имя команды по списку разрешённых.
- **`freezePrototype: true`** — прототипы встроенных объектов заморожены, подмена `Object.prototype` чужим скриптом не влияет на мост к ядру.
- **Запрет навигации, новых окон и загрузок:** обработчики `on_navigation` (разрешён только адрес своего интерфейса), `on_new_window` (запрет), `on_download` (запрет). Разрешения браузера (камера, микрофон, геолокация, уведомления) отклоняются через `with_webview`.

### Разрешения (capabilities)
- Интерфейсу **не выдаются** права `fs:*`, `opener:*`, `shell:*`, `http:*`. Плагины `http`, `updater`, `websocket`, `upload`, `localhost`, `shell` не подключаются вовсе (запрет в `cargo-deny`).
- Плагин `dialog` используется только из Rust (выбор папки хранилища, окно подтверждения ссылки); его JS-права интерфейсу не выдаются.
- **Свои команды** перечисляются явно в `AppManifest::commands` (`build.rs`) и выдаются окну через файл разрешений `src-tauri/capabilities/main.json`. Команда, не попавшая в список, интерфейсу недоступна.
- Каждая команда проверяет типы и границы параметров на стороне Rust (`serde` с `deny_unknown_fields`, длины строк, относительные пути по компонентам) и работает только с открытым в этом окне хранилищем.

### Внешние ссылки
Своя команда Rust `open_external(url)`: проверяет схему (`http`, `https`, `mailto`, остальное отклоняется), показывает окно подтверждения **средствами ядра** (`tauri-plugin-dialog` из Rust, полный адрес, по умолчанию кнопка «Открыть в браузере»), после подтверждения передаёт адрес ОС крейтом `open` 5.4.5. Интерфейс не может обойти подтверждение: у него нет ни прав `opener`, ни другой команды открытия.

### Цепочка поставок и проверка сети
- **`cargo-deny` 0.20** (`src-tauri/deny.toml`, конфигурация из исследования крейтов): лицензии только совместимые с GPL-3.0; запрет сетевых крейтов (`reqwest`, `hyper`, `h2`, `rustls`, `native-tls`, `openssl`, `socket2`, `tungstenite` и др.) и сетевых плагинов Tauri; запрет функций `tokio/net`, `mio/net`, `tauri/devtools`, `tauri/native-tls*`, `tauri/rustls-tls`; неизвестные реестры и git-источники запрещены; версии без `*`. Цели в `[graph]` — только десктопные (Windows, macOS, Linux): `reqwest` в Tauri есть только для мобильных целей.
- **`cargo tree` по каждой десктопной цели** в CI с поиском сетевых крейтов — второй, независимый от `cargo-deny` способ. Ожидаемо пусто; на Linux допускается `mio` без функции `net`.
- **`cargo-about` 0.9** — список лицензий для ИБ; **`cargo-cyclonedx` 0.5** — SBOM, прикладывается к выпуску вместе с SBOM npm-зависимостей интерфейса.
- **Проверка исходников интерфейса на сетевой код** (`fetch`, `XMLHttpRequest`, `WebSocket`, `EventSource`, `navigator.sendBeacon`, динамический `import()` с внешним адресом) — по синтаксическому дереву TypeScript/Svelte, а не только регулярными выражениями: регулярка пропускает обращение через скобки (`window['fe'+'tch']`) и ложно срабатывает на строки и комментарии. Проверяется собранный интерфейс, а не только исходники. CSP остаётся последним рубежом.
- **Лицензии npm-зависимостей интерфейса** проверяются с разбором выражений SPDX со скобками и `AND`/`OR` (`(MIT OR Apache-2.0)`, `(MIT AND CC-BY-3.0)`): строковое сравнение такие выражения пропускает или отклоняет ошибочно.

### Пути и CI
- **Зарезервированные имена Windows** (`CON`, `PRN`, `AUX`, `NUL`, `COM1`–`COM9`, `LPT1`–`LPT9`, в том числе с расширением: `nul.md`) отклоняются в каждом компоненте относительного пути, приходящего от интерфейса, — не только при создании файла, но и при любом обращении: путь `\\.\`-подобного устройства не должен открыться как файл. Это часть порядка проверки контура (исследование крейтов, раздел «Контур хранилища»).
- **GitHub Actions закрепляются по SHA коммита** (`uses: actions/checkout@<sha> # v5`), а не по метке: метку можно перенести на другой код. Обновления закреплений — отдельными коммитами с проверкой.

## Почему
Каждая мера закрывает свой путь утечки независимо: CSP и запрет навигации — сеть со страницы; разрешения и `AppManifest::commands` — лишние команды; isolation и `freezePrototype` — подмену моста; `cargo-deny` и `cargo tree` — сетевой код в зависимостях. Падение одной меры не открывает канал.

## Последствия
- Каждая новая команда ядра добавляется в три места: код, `AppManifest::commands`, файл разрешений — и в тест контракта.
- Isolation pattern добавляет немного задержки на каждый вызов; замер — в задаче контракта команд.
- Все меры вносятся в `SECURITY.md` со ссылками на файлы `src-tauri/...`.

## Отклонено
- Права плагина `opener` для интерфейса: открытие ссылки без подтверждения.
- Права `fs:*` с областью «хранилище»: область плагина расширяется выбором в диалоге, а символические ссылки и точки соединения NTFS он не проверяет так, как нужно нам; файлы — только своими командами.
- Проверка сетевого кода только регулярными выражениями (как в каркасе Electron): обходится и даёт ложные срабатывания.
