# ADR 0005. Платформа: Electron 45

Статус: принято 24.10.2026.

## Решение
Electron 45.0.x (Chromium 156, Node 24), начиная с первого патч-выпуска после 45.0.0. Версии зависимостей фиксируются точно, с lock-файлом. Electron обновляется раз в 2–3 месяца, пока ветка в поддержке (45 — до 27.04.2027).

## Последствия
Каждое обновление Electron — новый установщик и, вероятно, повторное согласование с ИБ. Процесс согласования обновлений нужно выяснить у ИБ.

## Отклонено
Electron 44: поддержка заканчивается в марте 2027.
