# ADR 0007. Служебные данные Chromium — во временной папке

Статус: **пересматривается** после ADR 0008: те же цели для WebView2 (папка данных во временной папке, нет кэшей и дампов, выключенные сетевые функции). Уточняет инвариант 2.

## Контекст
Chromium внутри Electron при каждом запуске создаёт служебные файлы (`Local State` и др.); выключить это нельзя. Требование: вне хранилища в профиле ОС — один файл приложения.

## Решение
- Все окна работают в сессии без записи на диск (партиция без `persist:`).
- Служебная папка Chromium (`sessionData`) перенаправляется во временную папку ОС с уникальным именем и удаляется при выходе. Остатки после аварийного завершения удаляются при следующем запуске.
- Кэши на диске отключены (`--disable-http-cache`, `--disable-gpu-shader-disk-cache`). Аппаратное ускорение не отключается: оно нужно графу.
- `crashReporter.start()` не вызывается: обработчик падений не запускается, дампов нет.
- В профиле ОС остаётся только файл со списком хранилищ.

## Сетевые меры, найденные при исследовании
- Словари проверки орфографии: `setSpellCheckerLanguages([])` на каждой сессии (одного выключения проверки недостаточно).
- Поиск прокси WPAD: ключ `--no-proxy-server`.
- Страховка: `--host-resolver-rules="MAP * ~NOTFOUND"` и отмена запросов на каждой сессии, включая сессию по умолчанию.

## Последствия
`SECURITY.md` честно описывает временную папку: что в ней лежит и что содержимого заметок там нет. Проверка — Process Monitor и сетевой монитор на чистой установке, в критериях приёмки каждого выпуска.

## Отклонено
Папка Chromium в `.rhizomind/`: технический мусор в хранилище и копия на каждое хранилище. Папка Chromium в AppData: ослабляет инвариант.
