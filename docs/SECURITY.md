# Модель безопасности Rhizomind (Secure-редакция)

Документ для службы информационной безопасности. Каждая мера ссылается на файл, где она реализована, чтобы её можно было проверить в коде. Документ обновляется вместе с каждым выпуском; выпуск не считается готовым, пока его меры не внесены сюда.

> **Состояние.** Меры с файлом в колонке «Где» реализованы в прототипе `prototype/src/` и будут перепроверены в выпуске 0.1. Файлы с префиксом `prototype/` относятся к прототипу (справочник, написанный до требований); по мере выполнения задач выпуска 0.1 ссылки заменяются на файлы нового кода (с задачи 0.2 — `src/`, `scripts/`, `electron-builder.yml`). Меры с номером выпуска запланированы. Целевые требования — в [product/requirements.md](product/requirements.md#безопасность), план выпусков — там же.

## Ключевые гарантии

1. **Нет сети.** В приложении нет сетевого кода: нет синхронизации, облака, телеметрии, автообновлений, загрузки внешних ресурсов, встроенного браузера и плагинов. Внешняя ссылка открывается в системном браузере только после подтверждения пользователя.
2. **Данные только в хранилище.** Заметки — обычные `.md`-файлы в папке, которую выбрал пользователь. Приложение читает и пишет только внутри неё. Служебные данные лежат в `.rhizomind/` внутри хранилища. Вне хранилища — один файл в профиле ОС со списком хранилищ (имена и пути), последним открытым хранилищем и размером окна.
3. **Chromium ничего не сохраняет.** Сессия браузерного движка только в памяти, дампов падений нет, журнал ошибок без содержимого заметок.
4. **Изоляция интерфейса.** Интерфейс не имеет доступа к Node.js, файловой системе и сети. Он может только вызывать узкий набор действий над открытым хранилищем.
5. **Без потери данных.** Приложение не затирает изменения файлов, сделанные снаружи. Удаление — только в корзину ОС.

## Меры защиты

### Сеть

| Мера | Где |
|---|---|
| Все запросы интерфейса, кроме `app://`, `data:`, `blob:`, отменяются до отправки | `prototype/src/main/security/lockdown.ts` |
| Политика контента (CSP): `connect-src 'none'`, только свои скрипты | `src/renderer/index.html` (выпуск 0.1, задача 0.2; заголовок CSP от протокола — задача 0.3) |
| Проверка орфографии Chromium (скачивает словари) отключена | `prototype/src/main/security/lockdown.ts`, `prototype/src/main/main.ts` |
| Загрузки файлов запрещены | `prototype/src/main/security/lockdown.ts` |
| Каналы обновления отключены (`publish: null`), автообновлений нет | `electron-builder.yml` |
| Автоматическая проверка исходников `src/` на сетевой код (`npm run check:network`, входит в `npm run verify` и CI) | `scripts/check-no-network.mjs`, тест `tests/unit/check-no-network.test.ts` |
| Лицензии production-зависимостей совместимы с GPL-3.0 (`npm run check:licenses`), перечень зависимостей — SBOM (`npm run sbom`) | `scripts/check-licenses.mjs`, `docs/dependencies.md` |
| Словари проверки орфографии не скачиваются: `setSpellCheckerLanguages([])` на каждой сессии (одного выключения проверки недостаточно — Electron issue #22995) | выпуск 0.1, ADR 0007 |
| Нет поиска прокси в сети (WPAD): `--no-proxy-server` | выпуск 0.1, ADR 0007 |
| Разрешение имён отключено: `--host-resolver-rules="MAP * ~NOTFOUND"`; отмена запросов на каждой сессии, включая сессию по умолчанию | выпуск 0.1, ADR 0007 |
| Внешняя ссылка передаётся системному браузеру только после подтверждения; только `http`, `https`, `mailto` | выпуск 0.1 |
| Свои CSS-темы не могут загрузить внешние ресурсы (`@import`, `url()` наружу блокируются CSP и сетевым выключателем) | выпуск 0.5 |

### Хранение и следы вне хранилища

| Мера | Где |
|---|---|
| Сессия Chromium только в памяти: без кэша, cookies и хранилищ на диске | выпуск 0.1, ADR 0007 |
| Служебные файлы Chromium, которые нельзя не создавать (`Local State` и др.), — во временной папке ОС с уникальным именем; удаляется при выходе, остатки после сбоя — при следующем запуске; содержимого заметок в ней нет | выпуск 0.1, ADR 0007 |
| Кэши на диске отключены: `--disable-http-cache`, `--disable-gpu-shader-disk-cache` | выпуск 0.1, ADR 0007 |
| Дампы падений отключены: обработчик падений не запускается (`crashReporter.start()` не вызывается) | выпуск 0.1, ADR 0007 |
| В профиле ОС один файл: список хранилищ, последнее открытое, размер окна | выпуск 0.1 |
| Служебные данные хранилища — только в `.rhizomind/` внутри него | выпуск 0.1 (настройки), 0.2 (индекс), 0.4 (раскладка) |
| Журнал ошибок в `.rhizomind/logs`: без содержимого заметок, с ограничением размера | выпуск 0.5 |

## Как проверить самостоятельно

- Запустить приложение под сетевым монитором (Wireshark, брандмауэр Windows с логированием) и убедиться в отсутствии исходящих соединений.
- Выполнить `npm run check:network`.
- Во время работы и после выхода проверить профиль ОС (Process Monitor): вне хранилища есть только файл со списком хранилищ, а временная папка Chromium после выхода удалена.
- Прочитать файлы из таблиц выше: весь код открыт.

## Известные ограничения

- Сборки пока не подписаны цифровой подписью. Для корпоративного распространения нужна подпись кода (Windows Authenticode, Apple Developer ID).
- Заметки хранятся без шифрования: защита данных на диске обеспечивается средствами ОС (BitLocker, FileVault, LUKS). Шифрование появится только по требованию ИБ.
