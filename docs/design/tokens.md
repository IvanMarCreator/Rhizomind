# Rhizomind 0.1 — переменные темы и размеры

Источник: Figma «Rhizomind — дизайн 0.1», коллекция переменных «Тема», режимы Light и Dark; страница «0.1 — итог».
Выбранный вид: концепт К2 (1А · 2Б · 3Б · 4В · 5Б), акцент индиго.
В CSS: `--имя` с заменой `/` на `-` (например `bg/app` → `--bg-app`). Тёмная тема — тот же набор имён с другими значениями.

## Цвета

Акцент выпуска — индиго. Переменные `accent/teal/*` и `accent/copper/*` остались от сравнения вариантов, в приложение их не переносить. В коде удобно завести псевдонимы `--accent`, `--accent-text`, `--accent-subtle` → `accent/indigo/*`.

Контраст: основной и вторичный текст ≥ 7:1 и ≥ 4.5:1 в обеих темах; `text/muted` около 4.5:1; `text/faint` и `link/unresolved` около 3–4:1 — так задумано для приглушённых элементов, но для длинного текста их не использовать.

## Шрифты

| Роль | Шрифт | Размер / межстрочный | Начертание |
|---|---|---|---|
| Интерфейс (дерево, меню, кнопки, строка над заметкой) | Inter (OFL 1.1), на Windows можно Segoe UI | 13 / авто; подписи 12; заголовок «ФАЙЛЫ» 11, разрядка 6% | Regular; Medium для активного и кнопок; Semi Bold для заголовков диалогов (15) |
| Заголовок окна Windows | Inter | 12 | Regular, `text/muted` |
| Текст заметки | Inter | 16 / 26 | Regular; жирный = Semi Bold |
| Заголовок заметки (H1 = имя файла) | Inter | 28 / 36 | Bold |
| Заголовок 2 | Inter | 21 / 27 | Semi Bold, отступ сверху 12 |
| Заголовки 3–6 | Inter | 18 / 17 / 16 / 16 | Semi Bold (в макете нет, предложение) |
| Код в строке | JetBrains Mono (OFL 1.1) | 14 (0,88 от текста) | Regular, `text/secondary` |
| Блок кода, адрес ссылки | JetBrains Mono | 13 / 20 | Regular |

Шрифты встраиваются в приложение файлами (woff2), без загрузки из сети. IBM Plex Sans в итоговый вид не вошёл.
