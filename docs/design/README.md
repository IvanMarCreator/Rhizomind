## Ограничения Figma

Тариф Starter, место View: около 20 вызовов MCP в месяц, 1 режим на коллекцию переменных (поэтому темы — две коллекции «Тема / Light» и «Тема / Dark»).

`figma-pending/` — готовые тела вызовов `use_figma` для решений 5–6 и концептов; порядок — в `figma-pending/README.txt`. После запуска — `get_screenshot` по возвращённым id и очистка `figma.root.setSharedPluginData('rzm','lib','')`.
