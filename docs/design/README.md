Режим заметки (решение 72) переключается только кнопками «книга / карандаш» справа в строке над заметкой (Э1, Э4б, Э9, состояния — Э13) и Ctrl+E; в настройках режима нет. Метка отложенного параметра без известного номера выпуска — «в следующем выпуске», с известным — «с 0.2» / «в 0.5». В окне конфликта горячих клавиш Enter = «Отмена» (решение оркестратора 73). Моноширинный шрифт в исходном тексте — «в следующем выпуске» (решение оркестратора 74).

Цвета, шрифты и размеры для разработки — [tokens.md](tokens.md). Подсветки синтаксиса в блоках кода в 0.1 нет; переменные `code/*` — на будущее.
