## Решения в макетах (дизайнер, на подтверждение)

- Кнопка панели — значок «панель справа» (Lucide `panel-right`) последней в строке над заметкой, после «книга / карандаш»; нажата (`bg/active`), пока панель открыта. Без заметки строка остаётся (назад/вперёд и кнопка панели), путь и режим скрыты.
- Значки видов: «Обратные ссылки» — `link`, «Теги» — `hash`; подсказка при наведении — название вида и сочетание, если назначено.
- Строка обратной ссылки — исходный текст строки (как в файле, с `[[…]]`), ссылка выделена `accent/indigo/text` и Medium. Папка серым — только при повторе имени.
- Вид «Теги»: «#» бледнее имени; переключатель порядка — два значка (`arrow-down-a-z`, `arrow-down-wide-narrow`) справа от названия.
- Строка «Свойства»: шеврон, значок `list`, «Свойства» `text/muted`, справа — теги из блока маленькими плашками; рамка `border/default`. Раскрытый блок — исходный текст шрифтом заметки на фоне `bg/code`.
- Уведомления-вопросы (110, 111) — без крестика: закрываются только ответом. Итоговые — с крестиком. «Не удалось обновить ссылки…» висит до закрытия (решение 121).
- Окно вопроса: Enter — «Обновить ссылки» (кольцо фокуса), Esc — «Отменить переименование»; пока индекс строится, фокус на «Отменить переименование».
