## Открытые

### 98. Пункт «Вставить» в своём меню правой кнопки (задача 2.19)

**Суть.** Своё меню (решение 97) умеет «Вырезать», «Копировать», «Выделить всё» без новых прав. «Вставить» из меню требует, чтобы программа сама читала буфер обмена: в WebView2 это разрешение ClipboardRead, сейчас все разрешения движка отклоняются (`SECURITY.md`). Ctrl+V с клавиатуры работает как раньше — это встроенная вставка движка, а не чтение буфера программой.

**Варианты.**
- **1. «Вставить» в меню серый, с подсказкой «Ctrl+V».** Плюсы: никаких новых прав, ИБ спрашивать нечего. Минусы: вставлять мышью из меню нельзя.
- **2. Разрешить чтение буфера странице программы** (WebView2 — только для своего источника, Linux — аналогичная настройка). Плюсы: «Вставить» работает. Минусы: любой скрипт в окне программы сможет читать буфер — новая строка для ИБ.
- **3. Новая команда ядра «прочитать текст из буфера»** по нажатию пункта. Плюсы: «Вставить» работает, доступ узкий — только по щелчку пользователя. Минусы: новое право окна и новый поток данных для описания ИБ.

**Рекомендация оркестратора:** 1 в выпуске 0.1; 3 — позже, если понадобится.
