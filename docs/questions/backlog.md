# Бэклог вопросов владельцу

Сюда оркестратор складывает вопросы, которые не может решить сам без владельца и без явной рекомендации. Владелец разбирает их утром. Формат — как в разговоре: номер, суть, варианты с плюсами и минусами, рекомендация (если есть).

## Открытые

### 82. Имя заметки в заголовке окна Windows

**Суть.** По макетам Э1/Э4б заголовок окна — «заметка — хранилище — Rhizomind». Сейчас у всех окон просто «Rhizomind», и при двух хранилищах окна не различить (находка QA Н2). Но заголовок окна видит сама Windows: панель задач, Alt+Tab, Диспетчер задач, а некоторые её функции (журнал действий / Timeline, Recall на новых ПК, программы учёта рабочего времени и специальные возможности) могут сохранять заголовки окон на диск или отправлять их дальше. Инвариант 2: «имена и содержимое заметок вне хранилища не пишутся» — сами мы ничего не пишем, но имя заметки становится доступно системе.

**Варианты.**
- **А. Только хранилище: «хранилище — Rhizomind».** Плюсы: окна различимы, имена заметок не уходят в систему. Минусы: расходится с макетом; имя хранилища всё же видно системе (оно уже есть в `vaults.json`).
- **Б. Как в макете: «заметка — хранилище — Rhizomind».** Плюсы: удобно, как в Obsidian. Минусы: имя открытой заметки видно Windows и её функциям; ИБ может спросить.
- **В. Настройка «Показывать имя заметки в заголовке окна» (по умолчанию выкл.).** Плюсы: выбор за пользователем, по умолчанию безопасно. Минусы: ещё одна настройка.

**Рекомендация оркестратора:** А сейчас (делается в задаче 2.11), В — в следующем выпуске, если захотите имя заметки.
