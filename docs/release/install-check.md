# Проверка установщиков на второй машине (выпуск 0.1, С9.9)

Для владельца. Делается на второй машине вместе с ручным сетевым аудитом ([security/network-audit.md](../security/network-audit.md)): сначала аудит портативной сборки, потом установщики. Результат — короткий ответ по каждому пункту «как ожидалось / что не так» (снимок экрана при расхождении).

Время: около 30 минут. Нужна учётная запись с правами администратора (для MSI) и обычная учётная запись без прав (для NSIS) — можно одна машина с двумя учётными записями.

## Что скачать

Файлы выпуска собирает GitHub Actions, прогон «Выпуск» (`.github/workflows/release.yml`): на странице прогона (вкладка **Actions** репозитория, нужен вход в GitHub) внизу — архив артефакта `rhizomind-release-0.1.0`. После тега `v0.1.0` те же файлы лежат в черновике на странице **Releases** (черновик видят только участники репозитория). В архиве:

| Файл | Что это |
|---|---|
| `rhizomind-0.1.0-windows-x64-portable.zip` | портативная сборка, без установки |
| `rhizomind-0.1.0-windows-x64.msi` | установщик MSI для всех пользователей (служба ИТ, нужны права администратора) |
| `rhizomind-0.1.0-windows-x64-user-setup.exe` | установщик для текущего пользователя (NSIS, без прав администратора) |
| `SHA256SUMS.txt` | контрольные суммы всех файлов |
| `sbom-rust.cdx.json`, `sbom-npm.cdx.json`, `licenses-rust.json` | перечни зависимостей и лицензий для ИБ |

**Сверить контрольные суммы** (PowerShell в папке загрузок):

```powershell
Get-FileHash .\rhizomind-0.1.0-* -Algorithm SHA256 | Format-Table Hash, Path
```

Хэши должны совпасть со строками в `SHA256SUMS.txt` (регистр букв не важен).

**Предупреждение SmartScreen.** Сборки не подписаны (сертификата подписи кода нет). При запуске Windows покажет «Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае». Это ожидаемо. Если в компании запуск неподписанных программ запрещён политикой — записать это как результат.

## 1. MSI — с правами администратора

1. Войти под учётной записью **с правами администратора**. Сетевой монитор аудита (если он запущен) не выключать — установщик не должен обращаться к сети.
2. Запустить `rhizomind-0.1.0-windows-x64.msi`. Ожидается: окна установщика на русском, запрос прав администратора (UAC), папка по умолчанию `C:\Program Files\Rhizomind\`. Установить.
3. Проверить, что появилось:
   - `C:\Program Files\Rhizomind\rhizomind.exe` и `Uninstall Rhizomind.lnk`;
   - в меню «Пуск» — «Rhizomind» (общее для всех пользователей); ярлык на общем рабочем столе;
   - в «Параметры → Приложения → Установленные приложения» — «Rhizomind», версия 0.1.0 (показывается отдельно от имени, под ним или в своей колонке), издатель «Rhizomind contributors».
4. Запустить Rhizomind из меню «Пуск»: открывается окно «Управление хранилищами». Создать хранилище, создать заметку, закрыть окно.
5. Войти под **другим** пользователем той же машины (если есть): Rhizomind есть в меню «Пуск» и запускается.
6. Удалить: «Установленные приложения» → Rhizomind → «Удалить» (нужны права администратора).
7. Проверить, что **не осталось**:
   - папки `C:\Program Files\Rhizomind\`;
   - ярлыков в меню «Пуск» и на рабочем столе;
   - записи в «Установленные приложения»;
   - раздела реестра `HKEY_CURRENT_USER\Software\Rhizomind contributors` (`regedit` или `Test-Path 'HKCU:\Software\Rhizomind contributors'` → `False`).
8. Проверить, что **осталось** (это данные пользователя, установщик их не трогает): папка хранилища с заметками и `%LOCALAPPDATA%\Rhizomind\vaults.json` (список хранилищ). Их удаляют вручную, если нужно.

## 2. NSIS — без прав администратора

1. Войти под учётной записью **без прав администратора**.
2. Запустить `rhizomind-0.1.0-windows-x64-user-setup.exe`. Ожидается: окна на русском, **без запроса прав администратора**, папка по умолчанию `C:\Users\<имя>\AppData\Local\Programs\Rhizomind`. В конце — галочки «Добавить ярлык на рабочий стол» (**снята по умолчанию**, решение 107) и «Запустить Rhizomind». Галочку ярлыка оставить снятой.
3. Проверить, что появилось:
   - `%LOCALAPPDATA%\Programs\Rhizomind\rhizomind.exe` и `uninstall.exe`;
   - в меню «Пуск» этого пользователя — «Rhizomind»;
   - ярлыка «Rhizomind» на рабочем столе **нет** (галочка была снята);
   - в «Установленные приложения» — «Rhizomind», версия 0.1.0 (отдельно от имени), издатель «Rhizomind contributors»;
   - **ничего** в `C:\Program Files\` и у других пользователей.
4. Запустить Rhizomind, создать новое хранилище (хранилище из раздела 1 создано другим пользователем, и его папка может быть недоступна), создать заметку, закрыть.
5. Удалить: «Установленные приложения» → Rhizomind → «Удалить». В окне удаления есть галочка «Удалить данные приложения» — **оставить снятой**.
6. Проверить, что **не осталось**: папки `%LOCALAPPDATA%\Programs\Rhizomind\` (пустая папка `%LOCALAPPDATA%\Programs` может остаться — это стандартная папка Windows), ярлыков, записи в «Установленные приложения», раздела `HKEY_CURRENT_USER\Software\Rhizomind contributors`.
7. Проверить, что **осталось**: хранилище с заметками и `%LOCALAPPDATA%\Rhizomind\vaults.json`.
8. Поставить NSIS ещё раз и удалить **с галочкой** «Удалить данные приложения»: после этого нет и папки `%LOCALAPPDATA%\Rhizomind\` (список хранилищ). Сами хранилища с заметками остаются всегда — установщик их не трогает.

## 3. Портативная сборка

1. Распаковать `rhizomind-0.1.0-windows-x64-portable.zip` в любую папку (например, на флешку). Внутри — `rhizomind.exe` и `LICENSE.txt`.
2. Запустить `rhizomind.exe` — без установки и без прав администратора.
3. Удаление — удалить папку. Список хранилищ остаётся в `%LOCALAPPDATA%\Rhizomind\vaults.json`, как и после установщиков.

## Что должно и не должно остаться — сводка

| После удаления | MSI | NSIS | Портативная |
|---|---|---|---|
| Файлы программы | нет | нет | удаляются вместе с папкой |
| Ярлыки, запись в «Установленные приложения» | нет | нет | — (их не было) |
| `HKCU\Software\Rhizomind contributors` | нет | нет | — (не создаётся) |
| `%LOCALAPPDATA%\Rhizomind\vaults.json` (список хранилищ) | остаётся | остаётся; удаляется галочкой «Удалить данные приложения» | остаётся |
| Хранилища с заметками | остаются | остаются | остаются |
| Записи Windows о запуске программ (`UserAssist`, `MuiCache`) и служебные записи WebView2 | остаются — их делает Windows для любой программы (`docs/SECURITY.md`, «Записи вне хранилища») | то же | то же |

## Сеть при установке

Установщики не скачивают ничего: в них нет загрузчика WebView2 (используется системный), нет автообновления и телеметрии. Если сетевой монитор аудита во время установки или удаления увидел соединение процесса `msiexec.exe`, `rhizomind-…-setup.exe`, `uninstall.exe` или `Un_*.exe` — это нарушение, записать адрес. Обращения самой Windows (проверка SmartScreen для неподписанного файла — `smartscreen.exe`, обновления) к установщику не относятся, но их тоже стоит записать.

Ту же установку, запуск и удаление CI делает на чистой машине при каждой сборке выпуска (`tests/installer/check-installers.ps1`, отчёт — артефакт `installer-check` прогона «Выпуск»); проверка на второй машине подтверждает это на настоящей Windows с UAC и без прав администратора.
