## [0.1.0] — ГГГГ-ММ-ДД

Первый выпуск Secure-редакции «Основа»: локальная база знаний из связанных Markdown-заметок для Windows 10 и 11 без сети, синхронизации и телеметрии. Подробный журнал разработки по задачам — в истории репозитория (`CHANGELOG.md` до коммита `663379b`) и в `docs/reviews/`.

### Добавлено

**Хранилища**
- Хранилище — обычная папка с Markdown-файлами на диске; приложение ничего не переводит в свой формат, служебные данные — в папке `.rhizomind/` внутри хранилища.
- Окно «Управление хранилищами»: создать хранилище, открыть существующую папку как хранилище, убрать из списка (файлы не удаляются). Каждое хранилище — в своём окне; уже открытое получает фокус.
- Переключатель хранилищ в окне; размер и положение окна каждого хранилища запоминаются.
- Окно «Настройки хранилища»: ширина текста и размер шрифта, папка для новых заметок, подтверждение удаления, предел размера заметки для редактирования, тема, горячие клавиши.
- Хранилище на флешке или сетевом диске: если носитель пропал, приложение сообщает об этом и не теряет уже записанное.

**Дерево файлов**
- Все папки и файлы хранилища, папки сверху, естественный порядок имён по-русски; вложения показываются с меткой типа.
- Создание, переименование, перемещение перетаскиванием и удаление заметок и папок; проверка имён по правилам Windows с понятными пояснениями.
- Удаление — в корзину Windows; на диске без корзины (флешка, сетевая папка) — безвозвратно и только после отдельного подтверждения.

**Редактор**
- Живой предпросмотр: заголовки, жирный, курсив, зачёркнутый, код, цитаты, списки, задачи с флажками, горизонтальная линия, ссылки; разметка видна только у элемента с курсором.
- Живой предпросмотр близко к макету: промежутки между абзацами, заголовками, списками, цитатами и блоками кода; вложенные пункты сдвинуты на ровный шаг; номер списка в колонке маркера, как точка; имя заметки, маркеры и флажки задач растут вместе с размером шрифта.
- Режим исходного текста (Ctrl+E).
- Enter продолжает списки, задачи и цитаты; номера списка пересчитываются при сдвиге (Tab, Shift+Tab) и удалении строк; парные квадратные скобки.
- Своё контекстное меню правки текста.
- Автосохранение; ввод записывается и при закрытии окна, и при выходе из Windows или выключении компьютера.
- Кодировки и концы строк файла (UTF-8 с BOM и без, CRLF и LF) сохраняются как были; файл не в UTF-8 открывается только для чтения.

**Связи между заметками**
- Вики-ссылки `[[Заметка]]`, `[[Папка/Заметка]]`, `[[Заметка#Раздел]]`, `[[Заметка|псевдоним]]`; неразрешённая ссылка видна сразу.
- Автодополнение после `[[`; щелчок по ссылке на несуществующую заметку создаёт её.
- Быстрый переход по имени заметки (Ctrl+O) с нечётким поиском.
- История переходов: назад и вперёд (Alt+← / Alt+→).
- Имена сравниваются без учёта регистра и формы записи Unicode, как в файловой системе Windows.

**Изменения снаружи**
- Приложение следит за папкой хранилища: изменения, сделанные в Проводнике, Блокноте или git, сразу видны в дереве и в открытой заметке.
- Если заметку одновременно изменили в приложении и снаружи, сохраняются обе версии — ничего не затирается.
- Переименование или перенос открытой заметки снаружи не закрывает её; удаление снаружи закрывает.

**Интерфейс**
- Светлая и тёмная темы, режим «как в системе».
- Весь интерфейс на русском.
- Горячие клавиши переназначаются в настройках.
- Имя заметки и хранилища — в заголовке окна.
- Повторный запуск программы выводит вперёд уже открытое окно, а не запускает вторую копию.

**Установка**
- Портативная сборка: zip с `rhizomind.exe`, установка не нужна.
- Установщик MSI для всех пользователей (служба ИТ, нужны права администратора): программа в `C:\Program Files\Rhizomind`.
- Установщик для текущего пользователя (NSIS, без прав администратора): программа в `%LOCALAPPDATA%\Programs\Rhizomind`.
- К выпуску приложены перечни зависимостей (SBOM, CycloneDX), список лицензий ядра и контрольные суммы SHA-256 всех файлов.

### Безопасность

- **Нет сети в коде приложения.** Сетевых возможностей в программе нет вовсе: проверяется при каждой сборке (запрещённые сетевые библиотеки, проверка кода интерфейса, политика безопасности страницы без внешних адресов). Нет встроенного браузера, загрузок, телеметрии, автообновления, плагинов.
- **Внешняя ссылка** (`http`, `https`, `mailto`) уходит в системный браузер или почту только после подтверждения в окне с полным адресом.
- **Браузерный движок WebView2 не хранит данные страницы:** режим InPrivate — кэш, cookies и хранилища страницы только в памяти; служебная папка движка — во временной папке, удаляется при выходе; SmartScreen, меню и сочетания браузера выключены. Если защитная настройка движка не применилась, окно не открывается. Что движок и Windows всё же записывают: служебные ключи движка в реестре `HKCU\Software\Microsoft\EdgeWebView` и `HKCU\Software\Microsoft\EdgeUpdate` (без путей и имён заметок, решение 61), записи Windows о запуске программы `UserAssist` и `MuiCache` (решение 65), служебные записи компонентов Windows и движка, найденные ручным сетевым аудитом, — кэш шейдеров видеокарты, настройки корзины, WinINet и зон безопасности, `bam`, уведомлений (без имён и текста заметок, решение 117; часть из них — ключи `HKCU` — перемещается с профилем Windows); если упадёт сам процесс движка, его дамп пишется локально во временную папку движка, в Microsoft не отправляется и удаляется вместе с папкой. Полный перечень — `docs/SECURITY.md`, «Записи вне хранилища».
- **Контур хранилища:** выход за папку хранилища невозможен ни через `..`, ни через ссылки и точки соединения NTFS. Все записи вне хранилища перечислены в `docs/SECURITY.md` («Записи вне хранилища»); список хранилищ — в `%LOCALAPPDATA%\Rhizomind\vaults.json` (не в перемещаемом профиле).
- **Граница ядро — интерфейс:** интерфейсу доступны только перечисленные команды ядра; доступа к файлам, оболочке и сети у интерфейса нет.
- **Установщики не обращаются к сети:** нет загрузки WebView2 (используется системный), нет автообновления, нет ассоциаций файлов и протоколов, переменная PATH не меняется. Удаление не оставляет файлов программы и записей установщика (NSIS может оставить пустую стандартную папку Windows `%LOCALAPPDATA%\Programs`); список хранилищ по умолчанию остаётся (данные пользователя).
- **Цепочка поставок:** версии зависимостей закреплены точно, лицензии совместимы с GPL-3.0, действия GitHub Actions закреплены по SHA коммита, скрипты установки npm-пакетов не запускаются.
- Модель безопасности, политики для службы ИТ и инструкция ручного сетевого аудита — `docs/SECURITY.md`, `docs/security/`.

### Известные ограничения

- Сборки не подписаны цифровой подписью: Windows покажет предупреждение SmartScreen при запуске установщика и программы.
- Нужен WebView2 Runtime (есть в Windows 11 и в обновлённой Windows 10); если его нет, ставит служба ИТ.
- Движок WebView2 — компонент Windows: его обращения к службам Microsoft описаны в `docs/SECURITY.md` и отключаются политиками ИТ.
- Заметки хранятся без шифрования: данные на диске защищаются средствами ОС (BitLocker).
- Движок WebView2 (встроенная библиотека входа Microsoft OneAuth) пишет локальный файл учётной записи Microsoft в `%LOCALAPPDATA%\Microsoft\OneAuth\accounts\` — без данных заметок; у процессов Rhizomind и движка сетевых событий нет (решение 118). Загрузка OneAuth противоречит мере решения 64, причина не установлена; как отключить запись, исследуется.
- При первом запуске под пользователем движок WebView2 может вызвать выход службы Windows `wlidsvc` в сеть к службе входа Microsoft (через брокер токенов WAM). Приложение гасит движок при закрытии последнего окна, чтобы этого не было (решение 64), но выход из Windows, выключение компьютера, «Снять задачу» и падение программы эту меру обходят; надёжно — отключить службу `wlidsvc` политикой ИТ.
- «Снять задачу» в «Диспетчере задач», падение программы или отключение питания: ввод с последнего автосохранения (до 1 секунды) может потеряться.
- Если флешка или внешний либо сетевой диск с хранилищем стал недоступен, несохранённый ввод может потеряться при закрытии окна; приложение об этом сообщает (решение 66).
- Установщик для текущего пользователя (NSIS) пишет ярлык меню «Пуск» в перемещаемый профиль (`%APPDATA%`), ярлык на рабочий стол — только если отметить галочку на последней странице (по умолчанию снята, при тихой установке ярлыка нет: рабочий стол может синхронизироваться с OneDrive; решение 107) — и записи в перемещаемый раздел реестра `HKCU`; MSI — запись `HKCU\Software\Rhizomind contributors`. Данных заметок в них нет. Для компаний — MSI или NSIS с ключами `/S /NS` (без ярлыка меню «Пуск»); подробно — `docs/SECURITY.md`, «Записи установщиков в перемещаемых местах».
